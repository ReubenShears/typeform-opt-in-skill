# Optimally landing page headlines: 10 per angle

100 candidate H1s for the Optimally VSL landing pages, 10 per hook key in the Ad Hooks sheet.
Same rules as the live sheet: promise the outcome rather than repeat the hook, `*asterisks*` mark the highlight, no em dashes.
Default subheadline for all of them: "Done-for-you marketing that funds itself, guaranteed."

The CSV next to this file uses the Ad Hooks sheet columns (Hook Key, Client ID, Headline, Subheadline, Angle, Ads Using It, Notes, Active, Sort) so rows can be pasted in with Active set to FALSE.
